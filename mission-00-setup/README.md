## 4. My understanding

A **Git repository** is a folder that Git tracks. Git records every change you make, so you can always go back to an earlier version of your work. A **GitHub repository** is the same project stored online so others can view it and so you have a safe backup.

The work is organised into separate mission folders because each mission covers a different topic. Keeping them separate makes it easy for the instructor to find and review each piece of work, and it keeps each commit focused on exactly one task.
