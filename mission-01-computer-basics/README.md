# Mission 1 — Know your computer

## 1. Task / objective

Explain how a computer processes information using the IPOS model (Input, Processing, Output, Storage). Identify hardware and software examples and classify each piece of software. Describe three computer-based systems from everyday life other than a laptop or mobile phone.

## 2. Work completed

- Traced the activity of searching a website through all four IPOS stages.
- Listed four hardware items and four software examples and classified each.
- Described three real-world computer-based systems with their inputs and outputs.
- Wrote explanations of the IPOS model and hardware/software categories in my own words.

## 4. My understanding

### Task 1.1 — IPOS trace: Searching the internet

**Activity chosen:** Typing a search query into a web browser and reading the results.

| Stage | What happens | Hardware / component |
|-------|-------------|----------------------|
| **Input** | I type the search query using the keyboard. The keyboard sends electrical signals for each keypress to the computer. | Keyboard |
| **Processing** | The CPU reads the keystrokes, the browser application interprets them as a search request, and the network adapter sends the query to the search engine's server over the internet. The server processes the query and sends back results. The CPU receives the response and prepares it for display. | CPU, RAM, network adapter |
| **Output** | The browser displays the search results on the screen. Each result is rendered as text and links that I can read. | Screen / display |
| **Storage** | The browser caches the page data on the SSD so that revisiting the page may be faster. The operating system also temporarily stores data in RAM while the page is open. | SSD (long-term), RAM (short-term) |

The activity moves through these stages in order: a physical action (keystroke) is converted into data, the CPU and software decide what to do with it, the result is shown to me, and the data is kept for future use.

### Task 1.2 — Hardware and software classification

| Item / software name | Hardware or software | Software type (if applicable) | Purpose |
|---------------------|---------------------|-------------------------------|---------|
| Keyboard | Hardware | Not applicable | Used to enter text and commands |
| Screen / display | Hardware | Not applicable | Shows visual output to the user |
| SSD (Solid-State Drive) | Hardware | Not applicable | Stores files, applications and the operating system permanently |
| RAM (Random Access Memory) | Hardware | Not applicable | Holds data that the CPU is currently using; faster than SSD but temporary |
| macOS | Software | Operating system software | Manages the computer hardware, file system, processes and user interface |
| Safari / Chrome | Software | Application software | Allows the user to browse the internet |
| Homebrew | Software | Utility software | Manages the installation, update and removal of developer tools and packages on macOS |
| Activity Monitor | Software | Utility software | Displays running processes, CPU usage and memory consumption so the user can manage system resources |

**Explanation of software types:**
- **Operating system software** manages the computer itself — it starts programmes, allocates memory and manages files. Without it the computer cannot run anything.
- **Application software** helps users perform specific tasks such as browsing, writing or editing photos.
- **Utility software** helps maintain or manage the computer — for example monitoring performance or installing tools.

## 5. Difficulties faced

No major difficulties. The IPOS trace required careful thinking about which stage each part of the activity belongs to — for example, deciding whether the network response counts as processing or input was initially unclear, but it is part of processing because the CPU is interpreting and acting on the data.

## 6. How I resolved them

Thinking through each stage step by step, and remembering that input is what comes from outside the CPU, while processing is everything the CPU does with it, resolved the uncertainty.
