## About this project

This repository contains my completed work for the **Digital Detective** Diwali Independent Learning Assignment. The assignment explores how computers work — from hardware and operating systems to Terminal commands, Python programs, number systems, version control, and computer networks.

Each mission covers a specific topic. Work was completed and committed separately for each mission so that progress is clearly visible in the Git history.

## Topics explored

- **IPOS model** — how a computer receives input, processes data, produces output and stores results
- **Hardware and software** — identifying and classifying components
- **Terminal (CLI)** — navigating directories, managing files, using flags and pipes
- **Operating system** — processes, storage, paths, permissions and OS responsibilities
- **Program execution** — compilers vs interpreters, running Python programs
- **Number systems** — decimal, binary and hexadecimal conversions
- **Text encoding** — ASCII and UTF-8 standards
- **Version control** — Git workflow, branches, commits and Pull Requests
- **Computer networks** — LAN, MAN, WAN, DNS, routers, protocols and client-server model

## How to run the number converter

The Python number converter is in the `mission-05-numbers-data/` folder.

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

When prompted, enter a positive decimal integer (for example `42`). The program will display its binary and hexadecimal equivalents.

## Short learning summary

Through this assignment I learned that computers process everything as binary numbers, that the operating system acts as the manager between hardware and applications, that version control with Git makes it safe to track and share changes, and that every device on a network uses addresses and protocols to communicate. Terminal commands give direct, precise control over a computer that graphical interfaces cannot always match.
